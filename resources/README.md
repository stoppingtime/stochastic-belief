# Synced Lean resources

This directory is maintained by `.github/workflows/sync-lean-resources.yml`.

The workflow stores read-only Markdown snapshots from useful Lean 4 resource collections. Upstream content is never executed by CI.

## Sources

### best-of-lean4

- Upstream: https://github.com/34j/best-of-lean4
- Mirrored files: `README.md`, `LICENSE`

### Lean prover community website

- Upstream: https://github.com/leanprover-community/leanprover-community.github.io/tree/lean4
- Mirrored files: `templates/learn.md`, `templates/teaching/resources.md`, `templates/did_you_prove_it.md`, `LICENSE`
- License: MIT (the upstream license is mirrored alongside the content)

The snapshots are convenience copies. For authoritative/current material, follow the upstream repositories.
